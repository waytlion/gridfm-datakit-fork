
It’s a large file of about 11GB. Hope it works.

●	It’s based on only the 1125 load buses, not the 2000 total.
●	It has all the years from 2002 to November 2025 (December 2025 load is not yet available from ERCOT).
●	The model changed slightly, including rooftop solar and relative humidity features.
●	I change the method for the corrected version of the loads (see below).
The following load columns exist in the file:
●	load:  modeled bus-level load
●	load_pc: modeled bus-level load per capita
●	load_corrected: corrected bus-level load 
●	load_pc_corrected: corrected bus-level load per capita
(The corrected versions of the load have been scaled using a rolling 30-day scale factor, so that the summed-up rolling load averages match the rolling ERCOT averages.)
